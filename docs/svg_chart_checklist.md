# SVG 图表输出检查指南

本文档描述了验证 SVG 图表输出是否符合数据定义的检查逻辑，用于指导图表渲染的开发和测试。

## 一、通用检查项

### 1. 画布和背景
- [ ] SVG 尺寸与指定的 width/height 一致
- [ ] 背景色正确（默认 #f4f7fd）

### 2. 标题区域
- [ ] 主标题文本正确
- [ ] 副标题文本正确（如有）
- [ ] 标题水平居中（x ≈ width/2）
- [ ] 标题和副标题垂直间距合理（约 16px）

### 3. 图例区域
- [ ] 图例项数量与数据一致
- [ ] 图例文本内容正确
- [ ] 图例颜色与系列/扇区颜色匹配
- [ ] 图例整体水平居中
- [ ] symbol 和文本垂直对齐（以 y 为中心）
- [ ] symbol 和文本间距合理（8px）

**图例布局算法**：
1. 使用 `create_text_layout` 测量每个文本的实际宽度
2. 计算每个 item 宽度：`symbol_size + item_gap + text_width + padding * 2`
3. 计算整体起始位置：`(width - total_width) / 2`
4. 文本使用 Left 对齐，位置在 symbol 右侧

### 4. 坐标轴
- [ ] X轴刻度数量和位置正确
- [ ] Y轴刻度数量和位置正确
- [ ] X轴名称显示正确（如有）
- [ ] Y轴名称显示正确（如有）
- [ ] 轴名称不超出画布边界
- [ ] 数值轴范围计算合理（根据数据范围动态决定是否包含0）

**轴名称位置**：
- X轴名称：水平居中于轴下方（y = bounds.y1 + 35）
- Y轴名称：垂直居中于轴左侧/右侧，旋转90度
- 左侧Y轴：x = max(bounds.x0 - 35, 15)，防止超出左边界

## 二、图表类型特定检查

### 柱状图 (Bar)
- [ ] 柱子数量与数据点一致
- [ ] 柱子高度与数据值成正比
- [ ] 柱子与X轴刻度水平对齐
- [ ] 柱子宽度一致，间距均匀
- [ ] 值标签位置正确：
  - 高柱子（>25px）：内部顶部，白色文字
  - 矮柱子（≤25px）：外部上方，柱子同色文字
- [ ] 值标签不重叠、不被遮挡

### 折线图 (Line)
- [ ] 数据点数量正确
- [ ] 数据点位置 (x, y) 与数据值对应
- [ ] 线条连接正确（平滑或直线）
- [ ] 平滑曲线控制点计算正确（Catmull-Rom 样条）

### 饼图 (Pie)
- [ ] 扇区数量与数据一致
- [ ] 扇区角度与数据值成正比
- [ ] 扇区颜色与 palette 对应
- [ ] 图例颜色与扇区颜色匹配
- [ ] 标签位置正确（内部或外部）

### 散点图/气泡图 (Scatter/Bubble)
- [ ] 气泡数量与数据点一致
- [ ] 气泡位置 (x, y) 与数据值对应
- [ ] 气泡大小与 size 值成正比
- [ ] 数据标签显示正确（如有）

### 面积图 (Area)
- [ ] 面积填充正确
- [ ] 填充颜色与系列颜色一致
- [ ] 边界线显示正确

## 三、文本布局检查

### 文本对齐原则
1. **Measure 阶段**：统一使用 Left 对齐创建 text layout
2. **布局阶段**：根据外部范围计算实际位置坐标
3. **对齐方式**：
   - Title: Center 对齐，锚点在画布中心
   - Legend 文本: Left 对齐，位置在 symbol 右侧
   - 轴标签: 根据位置选择 Left/Right/Center
   - 轴名称: Center 对齐

### 文本偏移计算
使用 `compute_text_offset` 根据 align 和 vertical_align 计算偏移量：
- Center 对齐：x 偏移 = -width/2
- Right 对齐：x 偏移 = -width
- Middle 垂直对齐：y 偏移 = -height/2

## 四、边界检查

### 防止文本超出画布
- [ ] 左侧Y轴名称：x ≥ 15px
- [ ] 顶部元素：y ≥ font_size
- [ ] 底部X轴名称：y ≤ height - 10
- [ ] 右侧元素：x + width ≤ canvas_width

### 防止元素重叠
- [ ] Title 和 Legend 间距 ≥ 20px
- [ ] Legend 和图表区域间距 ≥ 15px
- [ ] 数据标签不重叠

## 五、自动化检查脚本示例

```bash
# 检查 SVG 是否包含预期文本
grep -q "预期标题" chart.svg && echo "标题正确" || echo "标题缺失"

# 检查元素数量
rect_count=$(grep -o "<rect" chart.svg | wc -l)
echo "矩形数量: $rect_count"

# 检查颜色
grep -o "fill=\"#[0-9a-f]\{6\}\"" chart.svg | sort | uniq
```

## 六、常见问题和修复

### 问题1: 值标签被遮挡
**原因**: 柱子高度过小，标签放在内部被截断
**修复**: 根据柱子高度动态调整标签位置

### 问题2: 轴名称超出边界
**原因**: 未限制最小 x 位置
**修复**: `x = max(calculated_x, 15)`

### 问题3: Title 和 Legend 不对齐
**原因**: 对齐方式不一致或位置计算逻辑不同
**修复**: 统一使用 Center 对齐，锚点都在画布中心

### 问题4: X轴名称缺失
**原因**: 只处理了 Y 轴名称
**修复**: 添加 X 轴名称处理逻辑

## 七、验证流程

1. 运行示例生成 SVG
2. 对照数据定义检查每个元素
3. 使用浏览器打开 SVG 目视检查
4. 检查边界情况和边缘数据
5. 运行测试确保无回归
